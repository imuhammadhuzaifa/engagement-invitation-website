# Engagement Invitation Website

## Files
- index.html
- style.css
- script.js

## How to use
1. Keep all three files in the same folder.
2. Open `index.html` in a browser.
3. Edit the `invitation` object at the top of `script.js`:
   - personOne
   - personTwo
   - date
4. Change the event details directly inside `index.html`.
5. Replace the `YOUR PHOTO` box with your own image if desired.

## Important
The RSVP form is currently a front-end demo. To receive real RSVP submissions,
connect it to a backend, Google Form, Formspree, Firebase, or WhatsApp.

The design is engagement-focused, mobile-first, with a curtain-style opening,
animated invitation reveal, event details, countdown, RSVP and responsive layout.
